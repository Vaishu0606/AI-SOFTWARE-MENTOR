# Bob Sessions

This directory stores **real IBM Bob task-session evidence** for the IBM Bob 2.0 Hackathon submission.

## Contents

Each subdirectory or file in this directory corresponds to an actual Bob session used
during the development of the AI Software Mentor project.

Evidence may include:

- Screenshots of Bob task sessions (Plan mode, Agent mode, etc.)
- Session summaries exported from Bob
- Records of multi-step agentic workflows performed by Bob
- Parallel subagent investigation logs
- Code review sessions

## What is NOT here

- Fabricated or invented screenshots
- Placeholder images
- Content generated after the fact

## Purpose

The hackathon requires demonstrating that IBM Bob was used as a core component of the
development workflow — not just for individual code snippets, but for meaningful
multi-step software engineering tasks including planning, implementation, investigation,
code review, and verification.
